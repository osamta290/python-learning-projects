# 02 — User Registration System

## What it does
Collects users' names and ages, stores each user in a list, and displays all registered users when registration ends.

## Python concepts
- Lists and `append()`
- Functions
- `for` and `while` loops
- `break` and `continue`
- `try` / `except` and `ValueError`
- Input validation
- `lower()`
- f-strings

## Run
```bash
python main.py
```

Enter a positive whole number for the age. Type `yes` when asked if you want to register another user; any other answer ends registration.
