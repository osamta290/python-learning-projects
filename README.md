# Python Learning Projects

A collection of beginner Python projects built while learning programming step by step.

## Projects

1. [Age Checker](01-age-checker/) — practices variables, input, type conversion, conditions, and f-strings.
2. [User Registration System](02-user-registration/) — practices lists, loops, functions, input validation, and exception handling.

## Learning approach

Each project is built progressively. The code is intentionally beginner-friendly and will be improved as new Python concepts are learned.
