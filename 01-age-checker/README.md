# 01 — Age Checker

## What it does
Asks for a user's name and age, then prints whether the user is 18 or older.

## Python concepts
- Variables
- `input()` and `print()`
- Type conversion with `int()`
- `if` / `else`
- Comparison operator `>=`
- f-strings

## Run
```bash
python main.py
```

This is an early beginner project. It does not yet handle non-numeric age input.
